# Smart Budget - Privacy Policy

This repository hosts the official public Privacy Policy for the **Smart Budget** mobile application (`com.dravidsajin.smartbudget`).

## Live Website
Once GitHub Pages is enabled on this public repository, the privacy policy is live at:
`https://<your-github-username>.github.io/<repo-name>/`

## Deployment
1. Create a **public** repository on GitHub (e.g. `smart-budget-privacy`).
2. Run:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
3. Go to **Settings ➔ Pages** ➔ select branch `main` and root `/` folder ➔ Click **Save**.
